Servicio 02

Impermeabilizantes

Protección integral contra la humedad con sistemas adaptados a cada tipo de superficie, estructura y condición ambiental.

Contamos con una amplia gama de sistemas impermeabilizantes para cubrir todas las necesidades de protección en construcciones residenciales, comerciales e industriales.

Desde soluciones cementosas para muros hasta sistemas de poliéster de secado rápido, garantizamos durabilidad y eficiencia en cada aplicación.

Sistemas Base

  • Cementosos para muros de contención
  • Poliuretanos lámina pintro o galvanizada
  • Prefabricados
  • Gravilla
  • Arenado

Sistemas Avanzados

  • Poliéster-poliéster
  • Autoadheribles
  • Acrílicos de secado rápido
  • Para espejos de agua
  • Para muros llorones

Usos Especiales

  • Charolas de baño
  • Sistemas para jardineras
  • Sistemas para albercas
  • Áreas de alto tráfico
  • Terraza y azoteas
